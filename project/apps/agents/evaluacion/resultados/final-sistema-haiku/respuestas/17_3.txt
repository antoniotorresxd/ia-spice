* Wien bridge oscillator
* Valores comerciales (circuito): ideal -> comercial
*   R1: 10kohm -> 10kohm [E24, +0.00%]
*   C1: 10nF -> 10nF [E12, +0.00%]
*   R2: 10kohm -> 10kohm [E24, +0.00%]
*   C2: 10nF -> 10nF [E12, +0.00%]
*   Rf: 22kohm -> 22kohm [E24, +0.00%]
*   Rg: 10kohm -> 10kohm [E24, +0.00%]
* Semiconductores:
*   D1, D2: 2 x 1N4148 (diodo de conmutación de señal; modelo genérico)
*   X1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
Vdd vdd 0 DC 5
Vee vee 0 DC -5
R1 Vout n1 10k
C1 n1 nplus 10n
R2 nplus 0 10k
C2 nplus 0 10n
Rf Vout nminus 22k
Rg nminus 0 10k
D1 Vout nminus DMOD
D2 nminus Vout DMOD
.model DMOD D(IS=1e-14 N=1.4)
X1 nplus nminus Vout vdd vee OPAMP
.subckt OPAMP inp inn out vdd vee
Rin inp inn 1e6
Egain n1 0 inp inn 1e5
Rp n1 n2 1k
Cp n2 0 1p
Eout out 0 value={min(max(v(n2),-4.5),4.5)}
.ends
.ic v(Vout)=0.1
.control
tran 10u 20m
wrdata output.txt v(Vout)
meas tran vpp PP v(Vout) from=10m to=20m
meas tran tper TRIG v(Vout) VAL=0 RISE=50 TARG v(Vout) VAL=0 RISE=51
echo $&tper > output.txt
.endc
.end
