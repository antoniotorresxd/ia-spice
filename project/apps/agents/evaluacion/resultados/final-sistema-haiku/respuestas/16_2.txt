* RC phase-shift oscillator
* Valores comerciales (circuito): ideal -> comercial
*   C1: 10nF -> 10nF [E12, +0.00%]
*   R1: 10kohm -> 10kohm [E24, +0.00%]
*   C2: 10nF -> 10nF [E12, +0.00%]
*   R2: 10kohm -> 10kohm [E24, +0.00%]
*   C3: 10nF -> 10nF [E12, +0.00%]
*   Rg: 10kohm -> 10kohm [E24, +0.00%]
*   Rf: 300kohm -> 300kohm [E24, +0.00%]
* Semiconductores:
*   X1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
Vdd vdd 0 DC 5
Vss vss 0 DC -5
C1 Vout n1 10n
R1 n1 0 10k
C2 n1 n2 10n
R2 n2 0 10k
C3 n2 nm 10n
Rg nm 0 10k
Rf Vout nm 300k
X1 0 nm Vout vdd vss OPAMP
.subckt OPAMP inp inn out vp vn
Rin inp inn 1e6
Bout out 0 V='max(v(vn),min(v(vp),1e5*(v(inp)-v(inn))))'
.ends
.ic v(Vout)=0.1
.tran 10u 20m uic
.control
run
let vmax = maximum(v(Vout))
let vmin = minimum(v(Vout))
let pp = vmax - vmin
wrdata wave.txt v(Vout)
echo $&pp > output.txt
.endc
.end
