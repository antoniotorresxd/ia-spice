* RC phase-shift oscillator
* Valores comerciales (circuito): ideal -> comercial
*   Rf: 33kohm -> 33kohm [E24, +0.00%]
*   R1: 1kohm -> 1kohm [E24, +0.00%]
*   C3: 10nF -> 10nF [E12, +0.00%]
*   R2: 1kohm -> 1kohm [E24, +0.00%]
*   C1: 10nF -> 10nF [E12, +0.00%]
*   R4: 1kohm -> 1kohm [E24, +0.00%]
*   C2: 10nF -> 10nF [E12, +0.00%]
* Semiconductores:
*   X1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
VCC vcc 0 DC 12
VEE vee 0 DC -12
X1 0 vn vout opamp
Rf vout vn 33k
R1 vn 0 1k
C3 vc vn 10n
R2 vc 0 1k
C1 vb vc 10n
R4 vb 0 1k
C2 vout vb 10n
.subckt opamp inp inn out
Rin inp inn 1e6
Egain n1 0 inp inn 1e5
Rp n1 n2 1k
Cp n2 0 1n
Eout out 0 n2 0 1
.ends
.ic v(vout)=0.1
.tran 5u 20m 0 uic
.control
run
meas tran tmax MAX v(vout) from=10m to=20m
wrdata output.txt v(vout)
let vmid = v(vout)
print vmid
.endc
.end
