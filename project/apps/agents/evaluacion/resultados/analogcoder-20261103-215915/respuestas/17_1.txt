* Wien bridge oscillator
* Valores comerciales (circuito): ideal -> comercial
*   C1: 15.9nF -> 12nF || 3.9nF = 15.9nF [E12, -0.10%]
*   R2: 10kohm -> 10kohm [E24, +0.00%]
*   C2: 15.9nF -> 12nF || 3.9nF = 15.9nF [E12, -0.10%]
*   R3: 10kohm -> 10kohm [E24, +0.00%]
*   Rg: 10kohm -> 10kohm [E24, +0.00%]
*   Rf: 22kohm -> 22kohm [E24, +0.00%]
* Semiconductores:
*   X1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
VCC vcc 0 DC 15
VEE vee 0 DC -15
X1 vp vn vout OPAMP
C1 vp 0 15.9n
R2 vp 0 10k
C2 vp vf 15.9n
R3 vf vout 10k
Rg vn 0 10k
Rf vn vout 22k
.subckt OPAMP inp inn out
Rin inp inn 1e6
Egain n1 0 inp inn 1e5
Rp n1 n2 1k
Cp n2 0 159p
Eout out 0 n2 0 1
.ends
.ic v(vout)=0.1
.control
tran 10u 50m uic
meas tran tper TRIG v(vout) VAL=0 RISE=5 TARG v(vout) VAL=0 RISE=6
let fo = 1/tper
wrdata output.txt v(vout)
echo $&fo > output.txt
.endc
.end
