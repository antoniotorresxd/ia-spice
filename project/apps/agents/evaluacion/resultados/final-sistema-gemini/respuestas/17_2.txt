* Wien Bridge Oscillator
* Valores comerciales (circuito): ideal -> comercial
*   R1: 10kohm -> 10kohm [E24, +0.00%]
*   Rf: 24kohm -> 24kohm [E24, +0.00%]
*   C1: 159nF -> 120nF || 39nF = 159nF [E12, +0.00%]
*   R2: 1kohm -> 1kohm [E24, +0.00%]
*   C2: 159nF -> 120nF || 39nF = 159nF [E12, +0.00%]
*   Rload: 10kohm -> 10kohm [E24, +0.00%]
* Semiconductores:
*   X1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
VCC vcc 0 DC 5.0
VEE 0 vee DC 5.0
R1 vout feedback 10k
Rf feedback 0 24k
C1 feedback n1 159n
R2 n1 0 1k
C2 vout n1 159n
X1 feedback - vout vcc vee opamp
Rload vout 0 10k

.subckt opamp inp inn out vcc vee
Rin inp inn 1e6
Egain n1 0 inp inn 1e5
Rp n1 n2 1k
Cp n2 0 159n
Eout out 0 n2 0 1
.ends

.control
tran 0.01m 50m 0m
meas tran vpp PP v(vout) from=10m to=50m
echo $&vpp > output.txt
.endc
.end
