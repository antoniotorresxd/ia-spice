* Wien Bridge Oscillator
* Valores comerciales (circuito): ideal -> comercial
*   R1: 10kohm -> 10kohm [E24, +0.00%]
*   Rf: 24kohm -> 24kohm [E24, +0.00%]
*   C1: 10nF -> 10nF [E12, +0.00%]
*   R2: 15.9kohm -> 16kohm [E24, +0.53%]
*   C2: 10nF -> 10nF [E12, +0.00%]
*   R3: 15.9kohm -> 16kohm [E24, +0.53%]
* Semiconductores:
*   X1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
VCC vdd 0 DC 5.0
VEE 0 vee DC 5.0
.subckt opamp inp inn out vcc vee
Rin inp inn 1e6
Egain n1 0 inp inn 1e5
Rp n1 n2 1k
Cp n2 0 159n
Eout out 0 n2 0 1
.ends
X1 inn_op Vout Vout vdd vee opamp
R1 inn_op 0 10k
Rf Vout inn_op 24k
C1 inn_op n_mid 10n
R2 n_mid 0 16k
C2 Vout n_mid 10n
R3 Vout n_mid 16k
.control
tran 1u 50m 0
meas tran vpp PP v(Vout)
echo $&vpp > output.txt
.endc
.end
