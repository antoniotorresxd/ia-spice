* Wien Bridge Oscillator
* Valores comerciales (circuito): ideal -> comercial
*   R1: 15.9kohm -> 16kohm [E24, +0.53%]
*   C1: 10nF -> 10nF [E12, +0.00%]
*   R2: 15.9kohm -> 16kohm [E24, +0.53%]
*   C2: 10nF -> 10nF [E12, +0.00%]
*   Rf: 20kohm -> 20kohm [E24, +0.00%]
*   Rg: 10kohm -> 10kohm [E24, +0.00%]
* Semiconductores:
*   X1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
X1 vplus vminus Vout opamp
R1 vplus node1 16k
C1 node1 0 10n
R2 0 node1 16k
C2 Vout vplus 10n
Rf Vout vminus 20k
Rg vminus 0 10k

.subckt opamp inp inn out
Rin inp inn 1e6
Egain n1 0 inp inn 1e5
Rp n1 n2 1k
Cp n2 0 159n
Eout out 0 n2 0 1
.ends

.control
tran 1u 50m 0m
meas tran vpeak MAX v(Vout) from=25m to=50m
meas tran freq FREQ v(Vout) from=25m to=50m
echo $&freq > output.txt
.endc
.end
