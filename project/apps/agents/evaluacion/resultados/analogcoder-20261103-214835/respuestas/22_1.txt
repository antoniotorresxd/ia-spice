* Disparador de Schmitt no inversor
* Valores comerciales (circuito): ideal -> comercial
*   R1: 10kohm -> 10kohm [E24, +0.00%]
*   R2: 27kohm -> 27kohm [E24, +0.00%]
*   R3: 10kohm -> 10kohm [E24, +0.00%]
* Semiconductores:
*   X1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
Vin vin 0 SIN(0 2 1000)
R1 vin vplus 10k
R2 vplus vout 27k
R3 vplus 0 10k
X1 vplus 0 vout opamp
.subckt opamp inp inn out
Rin inp inn 1e6
Egain n1 0 inp inn 1e5
Rp n1 n2 1k
Cp n2 0 159n
Eout out 0 n2 0 1
.ends
Vcc vcc 0 5
Vee vee 0 -5
.control
tran 10u 2m 0
meas tran vpp PP v(vout)
echo $&vpp > output.txt
.endc
.end
