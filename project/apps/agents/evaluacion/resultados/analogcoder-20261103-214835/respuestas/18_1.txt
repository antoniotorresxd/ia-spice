* Practical Op-Amp Integrator
* Valores comerciales (circuito): ideal -> comercial
*   Rin: 122kohm -> 120kohm + 1.6kohm = 122kohm [E24, -0.06%]
*   Rf: 1.22Mohm -> 1.2Mohm + 16kohm = 1.22Mohm [E24, -0.06%]
* Semiconductores:
*   X1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
Vin vin 0 DC 0 AC 1 PULSE(-1 1 0 10n 10n 0.5m 1m)
Rin vin vminus 121600
Rf vminus vout 1216000
Cf vminus vout 1.2155e-08
X1 0 vminus vout opamp

.subckt opamp inp inn out
Rin inp inn 1e6
Egain n1 0 inp inn 1e5
Rp n1 n2 1k
Cp n2 0 159n
Eout out 0 n2 0 1
.ends

.control
ac dec 100 1 1e8
meas ac fint WHEN vdb(vout)=0 CROSS=1
echo $&fint > output.txt
.endc
.end
