* Integrador inversor practico, alimentacion simple de 0 a 5 V
* Valores comerciales (circuito): ideal -> comercial
*   RREF1: 10kohm -> 10kohm [E24, +0.00%]
*   RREF2: 10kohm -> 10kohm [E24, +0.00%]
*   R1: 10kohm -> 10kohm [E24, +0.00%]
*   RBIAS: 10kohm -> 10kohm [E24, +0.00%]
*   Cf: 20nF -> 10nF || 10nF = 20nF [E12, +0.00%]
*   Rf: 1Mohm -> 1Mohm [E24, +0.00%]
* Semiconductores:
*   XU1: 1 x TL081 (1 op-amp(s) en 1 x TL081 (JFET, ±15 V); simulado con macromodelo ideal (ganancia 1e5, un polo); modelo genérico)
VDD vdd 0 DC 5
VSS vss 0 DC 0
RREF1 vdd vref 10k
RREF2 vref 0 10k
VSIG Vin 0 SIN(0 10m 1k) AC 1
R1 Vin nminus 10k
RBIAS vdd nminus 10k
Cf nminus Vout 20n
Rf nminus Vout 1meg
XU1 vref nminus Vout vdd vss OPAMP

.subckt OPAMP inp inn out vp vn
BOUT out 0 V=limit(1e6*(V(inp)-V(inn)), V(vn)+0.1, V(vp)-0.1)
.ends OPAMP

.control
tran 1u 10m
wrdata output.txt v(Vout)
.endc
.end
