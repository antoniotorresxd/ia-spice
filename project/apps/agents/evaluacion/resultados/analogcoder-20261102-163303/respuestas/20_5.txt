### Task 1

#### Components Needed
- **Operational Amplifier (Op-Amp)**: An ideal or macromodel op-amp configured in an inverting summing amplifier topology.
- **Resistors**: 
  - $R_1$ for the first input channel ($Vin_1$).
  - $R_2$ for the second input channel ($Vin_2$).
  - $R_f$ as the feedback resistor.
- **Power Supply**: $Vdd$ for positive supply (+5.0V), and $Vss$ for negative supply (ground or -5.0V). For simplicity and standard single-supply/dual-supply conventions, we can use a dual supply or a virtual ground. Here we use dual supplies $+Vdd$ and $-Vss$, or reference them appropriately.
- **Input Signal Sources**: $Vin_1$, $Vin_2$.
- **Output Node**: $Vout$.

#### Inverting Summing Amplifier Configuration
1. **Op-Amp Setup**:
   - Non-inverting terminal (+) connected to ground ($0\text{V}$) to establish a virtual ground at the inverting terminal.
   - Inverting terminal (-) connected to the summing node (let's call it node $V_x$).
   - Output terminal connected to $Vout$.

2. **Resistor Network**:
   - **$R_1$** connected between $Vin_1$ and the inverting node ($V_x$).
   - **$R_2$** connected between $Vin_2$ and the inverting node ($V_x$).
   - **$R_f$** connected between the inverting node ($V_x$) and the output node ($Vout$).
   - To achieve the exact transfer function $Vout = -(Vin_1 + Vin_2)$, we set $R_1 = R_2 = R_f$ (e.g., $10\text{ k}\Omega$ each).

### Task 2

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Opamp Adder')

# Power Supplies for the input signals and Op-Amp
circuit.V('in1', 'Vin1', circuit.gnd, 1.0) # 1V input 1
circuit.V('in2', 'Vin2', circuit.gnd, 2.0) # 2V input 2

circuit.V('dd', 'Vdd', circuit.gnd, 5.0)  # Positive supply 5V
circuit.V('ss', circuit.gnd, 'Vss', 5.0)  # Negative supply -5V (referenced correctly)

# Resistors for the summing amplifier (R1 = R2 = Rf = 10k ohms)
# To achieve Vout = -(Vin1 + Vin2)
circuit.R('1', 'Vin1', 'Vx', 10@u_kΩ)
circuit.R('2', 'Vin2', 'Vx', 10@u_kΩ)
circuit.R('f', 'Vx', 'Vout', 10@u_kΩ)

# Op-Amp Subcircuit or behavioral model connection
# Using a subcircuit or behavioral voltage source for an ideal op-amp:
# Vout = A * (V_non_inverting - V_inverting)
# For an inverting amplifier: non-inverting = gnd, inverting = Vx
# We can model the op-amp using a VCVS (E element) with a very high gain (e.g., 1e5)
circuit.BehavioralSource('opamp', 'Vout', circuit.gnd, value='1e5 * (0 - {Vx})')

# Analysis Part
simulator = circuit.simulator()
```
