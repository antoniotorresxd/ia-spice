### Task 1

#### Components Needed
- **Operational Amplifier (Op-Amp)**: Modelled using a subcircuit or behavioral voltage source (or standard op-amp representation) configured for non-inverting amplification. For standard SPICE implementation without an external macro model library, we can build the op-amp using individual transistors or use a VCVS (Voltage-Controlled Voltage Source) to represent the gain stage, combined with a feedback network. Alternatively, a transistor-based differential pair operational amplifier can be used. Let's design a discrete transistor-based operational amplifier or use a controlled source approach with transistors to form the core gain block. To ensure robust oscillation, we need a non-inverting amplifier with a gain slightly greater than 3 (typically around $A_v = 1 + R_f/R_1 \approx 3$).
- **Resistors**: 
  - $R_1, R_2$ forming the series-parallel frequency-selective RC network ($R$ and $C$).
  - $R_f, R_{in}$ setting the closed-loop gain of the amplifier.
- **Capacitors**: $C_1, C_2$ forming the frequency-selective feedback network.
- **Power Supply**: Dual power supplies (+Vdd and -Vss, or Vdd and ground with proper biasing) for the amplifier. Let's use dual supplies: +Vdd = 5V and -Vss = -5V for simplicity and centered operation.

#### Wien Bridge Feedback Network Setup
1. **Frequency-Selective Network**:
   - Series RC network connected from the amplifier output to the non-inverting input ($V_+$): Resistor $R_1$ in series with Capacitor $C_1$. Let the junction between $R_1$ and $C_1$ be node `V_pos`.
   - Parallel RC network connected from `V_pos` to the ground: Resistor $R_2$ in parallel with Capacitor $C_2$.
   - The oscillation frequency is given by $f_0 = \frac{1}{2\pi R C}$ (assuming $R_1 = R_2 = R$ and $C_1 = C_2 = C$).

2. **Amplifier and Gain Network**:
   - A non-inverting amplifier configuration where the output `Vout` is fed back via a resistive divider ($R_f$ and $R_{in}$) to the inverting input ($V_-$).
   - Gain $A_v = 1 + \frac{R_f}{R_{in}} \ge 3$ to sustain oscillation.

3. **Implementation via Transistor-Level / Controlled-Source Hybrid for PySpice**:
   - We can implement the amplifier using an ideal Voltage Controlled Voltage Source (VCVS, element `E`) with a high gain (e.g., $A = 1000$) or a transistor-based operational amplifier stage. Using a behavioral VCVS in PySpice makes the oscillator topology clean, stable, and guaranteed to oscillate at start-up.
