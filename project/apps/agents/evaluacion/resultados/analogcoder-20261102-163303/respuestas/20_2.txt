### Task 1

#### Components Needed
- **Operational Amplifier (Op-Amp)**: A single ideal/behavioral or transistor-level op-amp configured in an inverting summing amplifier topology. For PySpice simulation, a behavioral voltage-controlled voltage source (or subcircuit) or standard ideal op-amp representation can be used. Here, we implement it using resistors and an ideal op-amp block / controlled source, or standard standard operational amplifier subcircuit model. Let's use a standard ideal differential amplifier / controlled source approach or op-amp representation supported by PySpice.
- **Resistors**: 
  - $R_1$ for input path 1 ($Vin1$)
  - $R_2$ for input path 2 ($Vin2$)
  - $R_f$ as the feedback resistor connected between the output and the inverting input
  - (To ensure unity gain for the adder such that $V_{out} = -(Vin1 + Vin2)$, we choose $R_1 = R_2 = R_f$).
- **Power Supply**: $V_{dd}$ (5.0 V) and $V_{ss}$ (Ground or -5.0V for dual supply, let's use a single/dual supply setup; for standard op-amp summing with ground reference, we can use a dual supply $\pm 5\text{V}$ or a single supply with a virtual ground. Let's use standard dual supplies $V_{dd} = 5\text{V}$ and $V_{ss} = -5\text{V}$).
- **Input Signal Sources**: $Vin1$, $Vin2$ (DC voltage sources for operating point calculation).

#### Op-Amp Adder Topology Setup
1. **Non-Inverting Terminal ($V_+$)**:
   - Connected to ground ($0\text{V}$) to set up the inverting summing amplifier configuration.
2. **Inverting Terminal ($V_-$)**:
   - Connected to $Vin1$ through resistor $R_1$.
   - Connected to $Vin2$ through resistor $R_2$.
   - Connected to $Vout$ through feedback resistor $R_f$.
3. **Output Terminal ($V_{out}$)**:
   - Provides the summed and inverted output voltage: $V_{out} = -(\frac{R_f}{R_1} Vin1 + \frac{R_f}{R_2} Vin2)$. By setting $R_1 = R_2 = R_f = 10\text{ k}\Omega$, we get $V_{out} = -(Vin1 + Vin2)$.

### Task 2

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Opamp Adder')

# Power Supplies for the op-amp
circuit.V('dd', 'Vdd', circuit.gnd, 5.0)   # +5V power supply
circuit.V('ss', 'Vss', circuit.gnd, -5.0)  # -5V power supply

# Input Signal Sources for testing the operating point
circuit.V('in1', 'Vin1', circuit.gnd, 1.0)  # 1V DC input 1
circuit.V('in2', 'Vin2', circuit.gnd, 2.0)  # 2V DC input 2

# Resistors for the Inverting Summer
# Choosing R1 = R2 = Rf = 10k ohms to get Vout = -(Vin1 + Vin2)
circuit.R('1', 'Vin1', 'Vminus', 10@u_kΩ)
circuit.R('2', 'Vin2', 'Vminus', 10@u_kΩ)
circuit.R('f', 'Vout', 'Vminus', 10@u_kΩ)

# Non-inverting terminal connected to ground
circuit.R('ground_ref', 'Vplus', circuit.gnd, 1@u_Ω)

# Behavioral model of an Ideal Op-Amp
# E-source (Voltage-Controlled Voltage Source) representing high-gain op-amp: Vout = A * (V+ - V-)
# Using a high gain A = 1e5
circuit.Vcr('opamp', 'Vout_internal', circuit.gnd, 'Vplus', 'Vminus', 100000)
# Adding a small output resistance or direct connection
circuit.R('out', 'Vout_internal', 'Vout', 1@u_Ω)

# Analysis Part
simulator = circuit.simulator()
```
