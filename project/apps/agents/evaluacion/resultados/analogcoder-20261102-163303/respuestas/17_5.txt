### Task 1

#### Components Needed
- **Operational Amplifier (Op-Amp)**: Modelled using a subcircuit or behavioral voltage source representing high-gain differential amplification. For this PySpice implementation, we use a controlled voltage source or a macromodel.
- **Resistors**: 
  - $R_1, R_2$ forming the feedback network for gain control.
  - $R_p, C_p$ (parallel RC network) and $R_s, C_s$ (series RC network) forming the frequency-selective Wien bridge feedback network.
- **Power Supply**: $V_{dd}$ (positive supply) and $V_{ss}$ (negative supply) for the op-amp.
- **Output Node**: `Vout`

#### Wien Bridge Oscillator Topology
1. **Op-Amp Setup**:
   - The op-amp is configured in a non-inverting amplifier topology to provide a voltage gain $A_v = 1 + \frac{R_2}{R_1}$. For sustained oscillations in a Wien bridge oscillator, the gain must be at least 3 ($R_2 = 2 R_1$).
   - Non-inverting terminal ($+$) connected to the midpoint of the Wien bridge.
   - Inverting terminal ($-$) connected to the feedback resistors $R_1$ and $R_2$.

2. **Wien Bridge Feedback Network**:
   - The series combination of $R_s$ and $C_s$ is connected from the output (`Vout`) to the non-inverting input.
   - The parallel combination of $R_p$ and $C_p$ is connected from the non-inverting input to the ground.
   - This bandpass filter network provides zero phase shift at the oscillation frequency $\omega_0 = \frac{1}{\sqrt{R_s R_p C_s C_p}}$ and an attenuation of $1/3$, which dictates the required op-amp gain.

3. **Amplitude Stabilization / Gain Network**:
   - Resistor $R_2$ connects from `Vout` to the inverting input.
   - Resistor $R_1$ connects from the inverting input to the ground.

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Wien Bridge Oscillator')

# Power Supplies for the Op-Amp (Dual Supply)
circuit.V('cc', 'Vcc', circuit.gnd, 15@u_V)
circuit.V('ee', 'Vee', circuit.gnd, -15@u_V)

# Wien Bridge Feedback Network Components
# Series RC branch connected between Vout and non-inverting input (node 'V_plus')
circuit.R('s', 'Vout', 'V_plus', 10@u_kΩ)
circuit.C('s', 'V_plus', 'Node_Series', 10@u_nF)

# Parallel RC branch connected between non-inverting input (node 'V_plus') and ground
circuit.R('p', 'Node_Series', circuit.gnd, 10@u_kΩ)
circuit.C('p', 'Node_Series', circuit.gnd, 10@u_nF)

# Op-Amp Non-Inverting Input Bias / Connection
# (Connecting the series capacitor to the parallel resistor node)
# Note: Node_Series is the node between Cs and Rp.

# Inverting Gain Network (Setting gain to slightly greater than 3, e.g., Rf = 20k, Rg = 10k -> Av = 3)
circuit.R('f', 'Vout', 'V_minus', 20@u_kΩ)
circuit.R('g', 'V_minus', circuit.gnd, 10@u_kΩ)

# Behavioral/Ideal Op-Amp Implementation using Controlled Sources for simulation
# Output voltage = Gain * (V+ - V-)
# Using a high gain differential voltage source to model the op-amp
circuit.VCVS('opamp', 'Vout', circuit.gnd, 'V_plus', 'V_minus', 1e5)

# Analysis Part
simulator = circuit.simulator()
```
