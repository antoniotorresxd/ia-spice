## Task 1: Design Plan

**Topology:** Inverting summing amplifier built around an operational amplifier. The op-amp is modeled as a high-gain voltage-controlled voltage source (VCVS), which is the standard behavioral op-amp macro-model in SPICE.

**Operating principle:** With the non-inverting input grounded and negative feedback applied, the inverting node (Vneg) is a virtual ground. The input currents sum through the feedback resistor, giving Vout = -(Vin1 + Vin2) when all resistors are equal.

**Components and connectivity:**

| Device | Type | Connection | Value |
|---|---|---|---|
| Vin1 | DC source | Vin1 to ground | 1.0 V |
| Vin2 | DC source | Vin2 to ground | 0.5 V |
| R1 | Resistor | Vin1 to Vneg (inverting input) | 10 kΩ |
| R2 | Resistor | Vin2 to Vneg (inverting input) | 10 kΩ |
| Rf | Feedback resistor | Vneg to Vout | 10 kΩ |
| E1 (op-amp) | VCVS, gain A = 1e6 | Output: Vout to ground; control: (+) ground, (−) Vneg | A = 1e6 |

**Design equations:**
- Non-inverting input: V+ = 0 V (ground).
- Virtual short: V− = V+ = 0 V.
- KCL at Vneg: (Vin1 − 0)/R1 + (Vin2 − 0)/R2 + (Vout − 0)/Rf = 0.
- With R1 = R2 = Rf = 10 kΩ: **Vout = −(Vin1 + Vin2)**.
- Expected result for the chosen inputs: Vout = −(1.0 + 0.5) = **−1.5 V**.

**Node summary:** Vin1, Vin2 (inputs), Vneg (summing node), Vout (output), ground (non-inverting input and reference).

## Task 2: PySpice Code

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Inverting Summing Amplifier (Opamp Adder)')

# Input DC sources (operating-point only, no AC)
circuit.V('in1', 'Vin1', circuit.gnd, 1.0@u_V)
circuit.V('in2', 'Vin2', circuit.gnd, 0.5@u_V)

# Input resistors to the inverting node (Vneg)
circuit.R('1', 'Vin1', 'Vneg', 10@u_kΩ)
circuit.R('2', 'Vin2', 'Vneg', 10@u_kΩ)

# Feedback resistor from output to inverting node
circuit.R('f', 'Vneg', 'Vout', 10@u_kΩ)

# Ideal-type op-amp macro-model: Vout = A * (V(+) - V(-)), with V(+) = ground
# VCVS(name, out+, out-, ctrl+, ctrl-, gain)
circuit.VCVS('op', 'Vout', circuit.gnd, circuit.gnd, 'Vneg', 1e6)

# Analysis Part
simulator = circuit.simulator()
```
