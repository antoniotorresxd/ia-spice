## Task 1: Design Plan

The circuit is a non-inverting Schmitt trigger built from a five-transistor (5T) OTA used as a comparator-type op-amp. Vin drives the non-inverting input. The output feeds back to the inverting input through a resistive divider (Rf, Rg) that is referenced to Vref = Vdd/2, which creates the positive feedback and the hysteresis.

### Op-Amp (5T OTA, Transistor Level)

| Device | Type | Drain | Gate | Source | Bulk | W / L |
|---|---|---|---|---|---|---|
| M1 | NMOS (input, +) | Nd1 | Vin | Vtail | GND | 10 µm / 1 µm |
| M2 | NMOS (input, −) | Vout | Vm | Vtail | GND | 10 µm / 1 µm |
| M3 | PMOS (diode-connected load) | Nd1 | Nd1 | Vdd | Vdd | 10 µm / 1 µm |
| M4 | PMOS (mirror load, output side) | Vout | Nd1 | Vdd | Vdd | 10 µm / 1 µm |
| M5 | NMOS (tail current source) | Vtail | Vbias | GND | GND | 40 µm / 1 µm |

- **Tail current:** Vbias = 1.0 V gives I_tail ≈ ½·kp·(W/L)·(Vbias − Vth)² = ½·100µ·40·(0.5)² ≈ 0.5 mA, so each input branch carries about 0.25 mA.
- **Polarity:** Vin rising raises M1 current, which pulls Nd1 down, which raises the M4 current, which pulls Vout up. So Vin → Vout is non-inverting at the op-amp level.

### Positive Feedback Network

| Element | Connection | Value |
|---|---|---|
| Rf | Vout ↔ Vm | 10 kΩ |
| Rg | Vm ↔ Vref | 10 kΩ |
| Vref | DC source, Vref to GND | 2.5 V |

The inverting-input node is V₋ = (Vout + Vref)/2 because Rf = Rg.

### Switching Thresholds
- Vout low ≈ 0.1 V gives the rising threshold V_TH,R ≈ (0.1 + 2.5)/2 ≈ 1.3 V.
- Vout high ≈ 4.3 V gives the falling threshold V_TH,F ≈ (4.3 + 2.5)/2 ≈ 3.4 V.
- Hysteresis width ≈ 2.1 V, centred around Vref.

### Supplies and Inputs
- Vdd = 5.0 V (DC supply)
- Vbias = 1.0 V (tail bias)
- Vref = 2.5 V (reference for the feedback divider)
- Vin = 2.5 V (DC operating-point input; no AC sources)

### Node List
- Vdd, GND
- Vin (input)
- Vout (output)
- Vm (M2 gate / feedback divider midpoint)
- Nd1 (M1 drain, M3 drain/gate, M4 gate)
- Vtail (M1/M2 sources, M5 drain)
- Vbias, Vref

## Task 2: PySpice Code

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Non-Inverting Schmitt Trigger')

# MOSFET models
circuit.model('nmos_model', 'nmos', level=1, kp=100e-6, vto=0.5)
circuit.model('pmos_model', 'pmos', level=1, kp=50e-6, vto=-0.5)

# Power supplies and bias sources
circuit.V('dd', 'Vdd', circuit.gnd, 5.0)      # 5 V supply
circuit.V('bias', 'Vbias', circuit.gnd, 1.0)  # tail-current bias (Vth + 0.5 V)
circuit.V('ref', 'Vref', circuit.gnd, 2.5)    # reference = Vdd/2
circuit.V('in', 'Vin', circuit.gnd, 2.5)      # DC input for operating point

# Five-transistor OTA (op-amp core)
# MOSFET(name, drain, gate, source, bulk, model, w, l)
circuit.MOSFET('1', 'Nd1', 'Vin', 'Vtail', circuit.gnd, model='nmos_model', w=10e-6, l=1e-6)   # M1 (+ input)
circuit.MOSFET('2', 'Vout', 'Vm', 'Vtail', circuit.gnd, model='nmos_model', w=10e-6, l=1e-6)   # M2 (- input)
circuit.MOSFET('3', 'Nd1', 'Nd1', 'Vdd', 'Vdd', model='pmos_model', w=10e-6, l=1e-6)           # M3 diode load
circuit.MOSFET('4', 'Vout', 'Nd1', 'Vdd', 'Vdd', model='pmos_model', w=10e-6, l=1e-6)          # M4 mirror output
circuit.MOSFET('5', 'Vtail', 'Vbias', circuit.gnd, circuit.gnd, model='nmos_model', w=40e-6, l=1e-6)  # M5 tail

# Positive feedback network (non-inverting Schmitt configuration)
circuit.R('f', 'Vout', 'Vm', 10@u_kΩ)   # Rf
circuit.R('g', 'Vm', 'Vref', 10@u_kΩ)   # Rg

# Analysis Part
simulator = circuit.simulator()
```
