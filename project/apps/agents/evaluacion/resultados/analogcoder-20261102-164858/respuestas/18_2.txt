## Task 1: Design Plan

The integrator is an inverting integrator built from a 5-transistor NMOS-input OTA, which serves as the op-amp, with an input resistor R1 and a feedback capacitor Cf.

**Target transfer function:** Vout/Vin = −1/(s·R1·Cf). With R1 = 10 kΩ and Cf = 10 pF, the time constant is 100 ns and the unity-gain frequency is about 1.6 MHz.

### Op-Amp (5T OTA)

**Differential pair**
- **M1** (NMOS, W = 20 µm, L = 1 µm): gate = Vbias (non-inverting input), drain = Xnode, source = Vs, bulk = Vs.
- **M2** (NMOS, W = 20 µm, L = 1 µm): gate = Vinn (inverting input), drain = Vout, source = Vs, bulk = Vs.

**Active load (current mirror)**
- **M3** (PMOS, W = 20 µm, L = 1 µm): diode-connected. Gate and drain = Xnode, source = Vdd, bulk = Vdd.
- **M4** (PMOS, W = 20 µm, L = 1 µm): gate = Xnode, drain = Vout, source = Vdd, bulk = Vdd.

**Tail current source**
- **M5** (NMOS, W = 20 µm, L = 1 µm): gate = Vtail, drain = Vs, source = ground, bulk = ground.

**Signal flow:** Increasing the non-inverting input (M1 gate) raises Vout, so Vbias is the non-inverting input. Increasing the inverting input (M2 gate, Vinn) lowers Vout, which is the required polarity for negative feedback.

### Integrator Network
- **R1** (10 kΩ): between Vin and Vinn (the op-amp inverting input).
- **Cf** (10 pF): between Vinn and Vout, providing the feedback that makes the circuit integrate.

### Bias Sources
- **Vdd** = 5.0 V.
- **Vbias** = 2.5 V, the common-mode reference on the non-inverting input.
- **Vin** = 2.5 V DC, so the DC operating point is balanced. Only the operating point is considered, with no AC source.
- **Vtail** = 1.5 V, which sets the tail current to roughly 0.1–0.2 mA and keeps all transistors in saturation.

### Node Summary
| Node | Connections |
|---|---|
| Vin | R1 (input side) |
| Vinn | R1, M2 gate, Cf |
| Vbias | M1 gate |
| Vtail | M5 gate |
| Xnode | M1 drain, M3 drain/gate, M4 gate |
| Vs | M1 source, M2 source, M5 drain |
| Vout | M2 drain, M4 drain, Cf |
| Vdd | M3 and M4 sources and bulks |

## Task 2: PySpice Code

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Op-Amp Integrator')

# Define the MOSFET models
circuit.model('nmos_model', 'nmos', level=1, kp=100e-6, vto=0.5)
circuit.model('pmos_model', 'pmos', level=1, kp=50e-6, vto=-0.5)

# Power supply and bias sources
circuit.V('dd', 'Vdd', circuit.gnd, 5.0)     # 5 V supply
circuit.V('in', 'Vin', circuit.gnd, 2.5)     # 2.5 V DC input (common-mode level)
circuit.V('bias', 'Vbias', circuit.gnd, 2.5) # 2.5 V reference on non-inverting input
circuit.V('tail', 'Vtail', circuit.gnd, 1.5) # 1.5 V gate bias for tail current source

# Op-amp: 5-transistor OTA
# Differential pair (NMOS)
circuit.MOSFET('1', 'Xnode', 'Vbias', 'Vs', 'Vs', model='nmos_model', w=20e-6, l=1e-6)
circuit.MOSFET('2', 'Vout', 'Vinn', 'Vs', 'Vs', model='nmos_model', w=20e-6, l=1e-6)

# Current mirror active load (PMOS)
circuit.MOSFET('3', 'Xnode', 'Xnode', 'Vdd', 'Vdd', model='pmos_model', w=20e-6, l=1e-6)
circuit.MOSFET('4', 'Vout', 'Xnode', 'Vdd', 'Vdd', model='pmos_model', w=20e-6, l=1e-6)

# Tail current source (NMOS)
circuit.MOSFET('5', 'Vs', 'Vtail', circuit.gnd, circuit.gnd, model='nmos_model', w=20e-6, l=1e-6)

# Integrator network: input resistor and feedback capacitor
circuit.R('1', 'Vin', 'Vinn', 10@u_kΩ)
circuit.C('f', 'Vinn', 'Vout', 10@u_pF)

simulator = circuit.simulator()
```
