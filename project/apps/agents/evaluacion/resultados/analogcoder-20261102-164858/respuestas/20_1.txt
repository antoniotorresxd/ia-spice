## Task 1: Design Plan

The adder is an inverting summing amplifier. Each input reaches the inverting node through its own resistor, and a feedback resistor sets the gain. With equal resistors, the output is Vout = -(Vin1 + Vin2).

**Op-amp core (modeled as a high-gain VCVS):**
- The op-amp is modeled as a voltage-controlled voltage source with open-loop gain A = 1e6.
- Non-inverting input (+) is tied to ground.
- Inverting input (-) is the summing node **Vn**.
- Output is **Vout**, with Vout = -A·V(Vn).

**Input network:**
- **R1** (10 kΩ): connects input **Vin1** to the summing node **Vn**.
- **R2** (10 kΩ): connects input **Vin2** to the summing node **Vn**.

**Feedback network:**
- **Rf** (10 kΩ): connects the output **Vout** back to the summing node **Vn**.

**Sources:**
- **Vin1**: DC source of 1.0 V, referenced to ground (operating point only, no AC).
- **Vin2**: DC source of 0.5 V, referenced to ground.

**Expected result:** With the high open-loop gain, V(Vn) ≈ 0 V (virtual ground), and Vout = -(1.0 + 0.5) = -1.5 V. The design uses 10 kΩ resistors so that the gain ratio Rf/R1 = Rf/R2 = 1.

**Connectivity summary:**
| Element | Connection |
|---|---|
| Vin1 source | Vin1 → GND |
| Vin2 source | Vin2 → GND |
| R1 | Vin1 ↔ Vn |
| R2 | Vin2 ↔ Vn |
| Rf | Vout ↔ Vn |
| Op-amp VCVS | out+ = Vout, out− = GND, in+ = GND, in− = Vn |

## Task 2: PySpice Code

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Inverting Summing Amplifier (Vout = -(Vin1+Vin2))')

# Input voltage sources (DC operating point only)
circuit.V('in1', 'Vin1', circuit.gnd, 1.0)   # Vin1 = 1.0 V
circuit.V('in2', 'Vin2', circuit.gnd, 0.5)   # Vin2 = 0.5 V

# Op-amp modeled as high-gain VCVS
# VCVS(name, out_p, out_n, in_p, in_n, gain)
# Non-inverting input grounded, inverting input = Vn
circuit.VCVS('op', 'Vout', circuit.gnd, circuit.gnd, 'Vn', 1e6)

# Input resistors
circuit.R('1', 'Vin1', 'Vn', 10@u_kΩ)       # R1
circuit.R('2', 'Vin2', 'Vn', 10@u_kΩ)       # R2

# Feedback resistor
circuit.R('f', 'Vout', 'Vn', 10@u_kΩ)       # Rf

# Analysis Part
simulator = circuit.simulator()
```
