## Task 1: Design Plan

The subtractor is built as a difference amplifier around a transistor-level op-amp. The op-amp is a 5-transistor OTA (PMOS differential pair, NMOS current-mirror load, PMOS tail current source). Four 10 kΩ resistors form the subtractor network, with the output fed back to the inverting input.

**Target relation.** With Ra = Rf = Rb = Rg = 10 kΩ and negative feedback forcing V(Vn) = V(Vp):
- V(Vp) = Vin2 · Rg/(Rb+Rg) = Vin2/2
- V(Vn) = (Vin1 + Vout)/2
- Setting V(Vn) = V(Vp) gives **Vout = Vin2 − Vin1**

**Op-amp devices (5T OTA, Vdd = 5 V):**
- **M1** (PMOS, W = 20 µm, L = 1 µm): input transistor. Gate = Vp (non-inverting input), source = Ntail, drain = Dm (diode-side node).
- **M2** (PMOS, W = 20 µm, L = 1 µm): input transistor. Gate = Vn (inverting input), source = Ntail, drain = Vout (op-amp output).
- **M3** (PMOS, W = 40 µm, L = 1 µm): tail current source. Source = Vdd, gate = Vbias, drain = Ntail. Bulk = Vdd.
- **M4** (NMOS, W = 10 µm, L = 1 µm): diode-connected mirror reference. Gate and drain = Dm, source = GND.
- **M5** (NMOS, W = 10 µm, L = 1 µm): mirror output. Gate = Dm, drain = Vout, source = GND.

Bulk terminals of the NMOS devices are tied to GND, and the bulk of M1 and M2 is tied to Ntail (their source).

**Bias.** Vbias = 4.2 V gives V_SG(M3) ≈ 0.8 V, so the tail current is about 90 µA and each input branch carries about 45 µA. The input pair then sits near V_SG ≈ 0.8 V, and all devices stay in saturation for Vin1 = 1 V and Vin2 = 2 V.

**Subtractor network (feedback resistors):**
- **Ra** = 10 kΩ between Vin1 and Vn
- **Rf** = 10 kΩ between Vn and Vout
- **Rb** = 10 kΩ between Vin2 and Vp
- **Rg** = 10 kΩ between Vp and GND

**Supplies and test inputs:**
- Vdd = 5 V
- Vbias = 4.2 V
- Vin1 = 1 V, Vin2 = 2 V (DC test values), so the expected output is Vout = 1 V.

**Connectivity summary:**
- Vout is the OTA output (M2/M5 drain node), and it is also fed back to Vn through Rf.
- Vin1 drives Vn through Ra. Vin2 drives Vp through Rb, and Vp is also tied to GND through Rg.

## Task 2: PySpice Code

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Op-Amp Subtractor')

# Device models
circuit.model('nmos_model', 'nmos', level=1, kp=100e-6, vto=0.5)
circuit.model('pmos_model', 'pmos', level=1, kp=50e-6, vto=-0.5)

# Power supply and DC input sources
circuit.V('dd', 'Vdd', circuit.gnd, 5.0)      # 5 V supply
circuit.V('bias', 'Vbias', circuit.gnd, 4.2)  # tail bias: Vdd - |Vth| - ~0.3 V overdrive
circuit.V('in1', 'Vin1', circuit.gnd, 1.0)    # subtrahend
circuit.V('in2', 'Vin2', circuit.gnd, 2.0)    # minuend (expected Vout = 1.0 V)

# Op-amp: 5-transistor OTA
# MOSFET(name, drain, gate, source, bulk, model, w, l)
# M1: non-inverting input (gate = Vp)
circuit.MOSFET('1', 'Dm', 'Vp', 'Ntail', 'Ntail', model='pmos_model', w=20e-6, l=1e-6)
# M2: inverting input (gate = Vn), output drain = Vout
circuit.MOSFET('2', 'Vout', 'Vn', 'Ntail', 'Ntail', model='pmos_model', w=20e-6, l=1e-6)
# M3: PMOS tail current source
circuit.MOSFET('3', 'Ntail', 'Vbias', 'Vdd', 'Vdd', model='pmos_model', w=40e-6, l=1e-6)
# M4: diode-connected NMOS mirror reference
circuit.MOSFET('4', 'Dm', 'Dm', circuit.gnd, circuit.gnd, model='nmos_model', w=10e-6, l=1e-6)
# M5: NMOS mirror output
circuit.MOSFET('5', 'Vout', 'Dm', circuit.gnd, circuit.gnd, model='nmos_model', w=10e-6, l=1e-6)

# Subtractor resistor network (all 10 kOhm)
circuit.R('a', 'Vin1', 'Vn', 10@u_kΩ)   # Ra: Vin1 -> inverting node
circuit.R('f', 'Vn', 'Vout', 10@u_kΩ)   # Rf: feedback from output
circuit.R('b', 'Vin2', 'Vp', 10@u_kΩ)   # Rb: Vin2 -> non-inverting node
circuit.R('g', 'Vp', circuit.gnd, 10@u_kΩ)  # Rg: non-inverting node to ground

# Analysis Part
simulator = circuit.simulator()
```
