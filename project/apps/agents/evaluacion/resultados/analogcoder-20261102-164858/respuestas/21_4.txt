## Task 1: Design Plan

The subtractor is a difference amplifier built around a transistor-level op-amp. The op-amp is a 5-transistor OTA with a PMOS current-mirror load, and the feedback network is four 10 kΩ resistors. With equal resistors, the transfer function is Vout = Vin2 − Vin1.

### Op-amp (5-transistor OTA)

- **M1 (NMOS, W=25 µm, L=2 µm)**: non-inverting input device. Gate = V+ (node Vplus), source = tail node, drain = diode node A.
- **M2 (NMOS, W=25 µm, L=2 µm)**: inverting input device. Gate = V− (node Vminus), source = tail node, drain = Vout (OTA output).
- **M3 (PMOS, W=22 µm, L=2 µm)**: diode-connected active load. Source = Vdd, gate = drain = node A.
- **M4 (PMOS, W=22 µm, L=2 µm)**: mirror load. Source = Vdd, gate = node A, drain = Vout.
- **M5 (NMOS, W=20 µm, L=2 µm)**: tail current source. Drain = tail node, source = ground, gate = Vbias.
- **Bulks**: NMOS bulks tied to ground, PMOS bulks tied to Vdd.

Tail current is about 50–60 µA, set by M5 with Vbias = 0.85 V. M3 and M4 mirror the M1 current into the output node, which gives the single-ended OTA output at Vout.

### Feedback and Input Network (difference amplifier)

- **R1 = 10 kΩ**: Vin1 to Vminus (inverting input).
- **R2 = 10 kΩ**: Vminus to Vout (feedback).
- **R3 = 10 kΩ**: Vin2 to Vplus (non-inverting input).
- **R4 = 10 kΩ**: Vplus to ground.

With R1 = R2 = R3 = R4:
- V+ = Vin2/2
- V− = (Vin1 + Vout)/2
- Negative feedback forces V− = V+, so Vout = Vin2 − Vin1.

### Supplies and Bias

- **Vdd = 5.0 V**
- **Vbias = 0.85 V** (gate of M5; gives V_ov ≈ 0.35 V)
- **Vin1 = 1.0 V**, **Vin2 = 3.0 V**
- **Expected result**: V+ = V− = 1.5 V, Vout = 2.0 V

### Operating-point check

- The common-mode input is 1.5 V, and the tail node sits near 0.8 V.
- M2 has Vds ≈ 2.0 − 0.8 = 1.2 V, which keeps it in saturation (V_ov ≈ 0.2–0.35 V).
- M3 and M4 remain in saturation because Vsd is roughly 0.8 V and 3 V, respectively.

### Device Models

- NMOS: kp = 100 µA/V², Vto = 0.5 V, λ = 0.02 V⁻¹
- PMOS: kp = 50 µA/V², Vto = −0.5 V, λ = 0.02 V⁻¹

## Task 2: PySpice Code

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Op-Amp Subtractor')

# Device models (Level 1)
circuit.model('nmos_model', 'nmos', level=1, kp=100e-6, vto=0.5, lambda_=0.02)
circuit.model('pmos_model', 'pmos', level=1, kp=50e-6, vto=-0.5, lambda_=0.02)

# Power supply and input sources
circuit.V('dd', 'Vdd', circuit.gnd, 5.0)      # 5 V supply
circuit.V('bias', 'Vbias', circuit.gnd, 0.85) # OTA tail bias
circuit.V('in1', 'Vin1', circuit.gnd, 1.0)    # Input 1 (DC)
circuit.V('in2', 'Vin2', circuit.gnd, 3.0)    # Input 2 (DC), expected Vout = 2.0 V

# ---------------- Op-amp: 5-transistor OTA ----------------
# MOSFET(name, drain, gate, source, bulk, model, w, l)
# M1: non-inverting input device (gate = Vplus), drain = node A (diode side)
circuit.MOSFET('1', 'NodeA', 'Vplus', 'Tail', circuit.gnd, model='nmos_model', w=25e-6, l=2e-6)
# M2: inverting input device (gate = Vminus), drain = Vout (OTA output)
circuit.MOSFET('2', 'Vout', 'Vminus', 'Tail', circuit.gnd, model='nmos_model', w=25e-6, l=2e-6)
# M3: PMOS diode-connected load
circuit.MOSFET('3', 'NodeA', 'NodeA', 'Vdd', 'Vdd', model='pmos_model', w=22e-6, l=2e-6)
# M4: PMOS mirror load
circuit.MOSFET('4', 'Vout', 'NodeA', 'Vdd', 'Vdd', model='pmos_model', w=22e-6, l=2e-6)
# M5: NMOS tail current source
circuit.MOSFET('5', 'Tail', 'Vbias', circuit.gnd, circuit.gnd, model='nmos_model', w=20e-6, l=2e-6)

# ---------------- Difference amplifier feedback network ----------------
circuit.R('1', 'Vin1', 'Vminus', 10@u_kΩ)   # R1
circuit.R('2', 'Vminus', 'Vout', 10@u_kΩ)   # R2 (feedback)
circuit.R('3', 'Vin2', 'Vplus', 10@u_kΩ)    # R3
circuit.R('4', 'Vplus', circuit.gnd, 10@u_kΩ)  # R4

# Analysis Part
simulator = circuit.simulator()
```
