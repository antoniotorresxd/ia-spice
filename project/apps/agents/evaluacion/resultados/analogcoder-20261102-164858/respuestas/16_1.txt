## Task 1: Design Plan

**Circuit type:** RC phase-shift oscillator. The core is an inverting common-source amplifier, and a three-section RC ladder feeds the output back to the amplifier input. Each RC section contributes about 60° of phase shift at the oscillation frequency, so the ladder provides 180° and the inverting stage provides the other 180°, giving 360° of loop phase. The amplifier gain must exceed the ladder attenuation of 1/29.

**Amplifier core (inverting gain stage)**
- **M1 (NMOS, W = 10 µm, L = 1 µm):** common-source amplifying transistor.
  - Gate = node **"-"** (amplifier input, at the end of the feedback ladder).
  - Source and bulk = ground.
  - Drain = **Vout**.
- **M2 (PMOS, W = 20 µm, L = 1 µm):** active current-source load, which gives high output resistance and therefore high gain.
  - Source and bulk = Vdd.
  - Gate = **Vbp** (4.0 V, so Vsg = 1.0 V).
  - Drain = **Vout**.
- **DC bias:** M1 gate is biased to 1.0 V (Vgs = Vth + 0.5 V). With kp·W/L ≈ 2 mA/V² for M1 and kp·W/L ≈ 2 mA/V² for M2, both devices carry about 250 µA and the output sits near Vdd/2. Simulated gain is roughly gm·(ro‖ro) ≈ 1 mS × 100 kΩ ≈ 100, which exceeds the required 29.

**Feedback RC ladder (three identical sections, R = 100 kΩ, C = 1 nF)**
- **C1:** Vout → n1.
- **R1:** n1 → ground.
- **C2:** n1 → n2.
- **R2:** n2 → ground.
- **C3:** n2 → "-" (gate of M1).
- **R3:** "-" → Vbias. The Vbias source is at 1.0 V DC and is AC ground, so R3 is the shunt resistor of the third section. It also sets the gate DC bias through the ladder, since the capacitors block DC.

**Oscillation frequency**

f0 = 1 / (2π·√6·R·C) = 1 / (2π·√6·100 kΩ·1 nF) ≈ 650 Hz

**Node summary**
- Vdd: 5.0 V supply.
- Vbias: 1.0 V NMOS gate bias, also the R3 return.
- Vbp: 4.0 V PMOS gate bias.
- "-": amplifier input (M1 gate).
- Vout: amplifier output (M1 and M2 drains).
- n1, n2: internal ladder nodes.

## Task 2: PySpice Code

```python
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('RC Phase-Shift Oscillator')

# Device models (lambda gives finite output resistance for the active load)
circuit.model('nmos_model', 'nmos', level=1, kp=200e-6, vto=0.5, **{'lambda': 0.02})
circuit.model('pmos_model', 'pmos', level=1, kp=100e-6, vto=-0.5, **{'lambda': 0.02})

# Power supply and DC bias sources
circuit.V('dd', 'Vdd', circuit.gnd, 5.0)     # 5 V supply
circuit.V('bias', 'Vbias', circuit.gnd, 1.0) # NMOS gate bias = Vth + 0.5 V
circuit.V('bp', 'Vbp', circuit.gnd, 4.0)     # PMOS gate bias = Vdd - |Vth| - 0.5 V

# Inverting amplifier core
# MOSFET(name, drain, gate, source, bulk, model, w, l)
circuit.MOSFET('1', 'Vout', '-', circuit.gnd, circuit.gnd, model='nmos_model', w=10e-6, l=1e-6)
circuit.MOSFET('2', 'Vout', 'Vbp', 'Vdd', 'Vdd', model='pmos_model', w=20e-6, l=1e-6)

# Three-section RC phase-shift feedback network (R = 100 kOhm, C = 1 nF)
R_val = 100e3
C_val = 1e-9
circuit.C('1', 'Vout', 'n1', C_val)
circuit.R('1', 'n1', circuit.gnd, R_val)
circuit.C('2', 'n1', 'n2', C_val)
circuit.R('2', 'n2', circuit.gnd, R_val)
circuit.C('3', 'n2', '-', C_val)
circuit.R('3', '-', 'Vbias', R_val)  # shunt resistor of the last section; also sets gate DC bias

# Analysis Part
simulator = circuit.simulator()
```
